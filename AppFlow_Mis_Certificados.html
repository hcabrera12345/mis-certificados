AppFlow Interactivo v2.0

Flujo con Carga de Comprobante QR, Lectura OCR por IA y Notificación por WhatsApp

1. Solicitud & QR Estático

El estudiante finaliza el curso y solicita su certificado.

  • [Acción] Escanear QR Genérico Muestra QR estático de pago (Yape/Plin/Banco).
  • [Acción] Subir Foto de Comprobante El alumno adjunta la captura del pago realizado.
2. Lectura Automática OCR (IA)

Worker asíncrono procesa la imagen cargada.

  • [IA Pipeline] Extracción de Datos Lee Nº Operación, Monto, Fecha y Emisor en <1s.
  • [Filtro Anti-Fraude] Verificación Hash Comprueba que el comprobante no sea duplicado.
3. Notificación WhatsApp Admin

Aviso push al teléfono del Administrador.

  • [Push WhatsApp] Mensaje con Detalles Envía datos leídos y enlace de aprobación directa.
  • [Acción Admin] Dar "OK" / Aprobar El admin aprueba la transacción desde WhatsApp o Dashboard.
4. Liberación de Certificado SHA-256

Generación e impresión del documento oficial.

  • [Render Engine] PDF con Sello QR Combina la plantilla personalizada con los datos del graduado.
  • [Notificación Alumno] Certificado Listo Alerta al alumno para descargar su PDF/PNG.

Matriz de Eventos y Endpoints API

Pantalla Acción Usuario / Sistema API Endpoint / Evento Resultado
Formulario Pago Subir comprobante imagen POST /api/payments/upload-receipt Dispara Worker OCR Vision
Worker Backend Análisis de IA completado POST /api/webhooks/whatsapp-notify Mensaje Push a WhatsApp Admin
WhatsApp Admin Click en "Aprobar Pago" / OK POST /api/payments/approve Cambia status a 'approved' & Emite PDF
Admin Dashboard Subir plantilla de certificado POST /api/templates/upload Guarda trasfondo y coordenadas JSON
